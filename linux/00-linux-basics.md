# Основы Linux
# Ядро
- Ядро — главная программа которая обращается к железу. Другие программы не взаимодействуют напрямую с железом/памятью. Все ресурсы распределяет ядро.
# Дистрибутив
- Дистрибутив — готовый набор программ в дополнение к ядру, чем уже можно пользоваться. Например у меня Ubuntu это дистрибутив, бывает ещё Debian, Astra. Но ядро у них одно Linux, а другие программы входящие в дистрибутивы могут отличаться.
# Shell
- Shell — программа которая обрабатывает вводимые команды. Оболочка в Ubuntu — bash, проверить это можно через echo $SHELL. Терминал — окно, shell — программа внутри него, которая понимает команды.
# Папки
- /etc — настройки 
- /var — меняющиеся данные, логи в var/log
- /home — домашняя папка, у меня /home/alex
- /usr — установленные программы
- /tmp — временные файл, чистятся при перезагрузке
