# Файлы и пути

## Абсолютный и относительный путь
абсолютный путь — путь файла или директории на который не влияет твой положение начинается с /
относительный путь — пусть до с того места где ты находишься

## Специальные обозначения: . .. ~ -
. текущая папка
.. папка выше 
~ домашний каталог текущего пользователя
- предыдущий каталог, можно прыгать туда сюда

## Навигация: pwd, cd, ls
pwd показывает директорию где я 
cd перемещение по директориям 
ls показывает содержимое директорий

## Работа с файлами: mkdir, touch, cp, mv, rm
mkdir создать директорию
touch создание файлов 
cp копирование всегда два аргумента
mv переименовать переместить всегда два аргумента
rm удалить без корзины

## Чтение файлов: cat, less, head, tail, man
cat выводит файл целиком удобен для коротких файлов
less чтение файла удобно для длинных файлов
head выводит начало файла 
tail выводит хвост файла
man справка
