# Файлы и пути

## Абсолютный и относительный путь
абсолютный путь — путь файла или директории на который не влияет твой положение начинается с /
относительный путь — пусть до с того места где ты находишься

## Специальные обозначения: . .. ~ -
. текущая папка
.. папка выше 
~ домашний каталог текущего пользователя
- предыдущий каталог, можно прыгать туда сюда

## Навигация: pwd, cd, ls
pwd показывает директорию где я 
cd перемещение по директориям 
ls показывает содержимое директорий

## Работа с файлами: mkdir, touch, cp, mv, rm
mkdir создать директорию
touch создание файлов 
cp копирование всегда два аргумента
mv переименовать переместить всегда два аргумента
rm удалить без корзины

## Чтение файлов: cat, less, head, tail, man
cat выводит файл целиком удобен для коротких файлов
less чтение файла удобно для длинных файлов
head выводит начало файла 
tail выводит хвост файла
man справка

## Немного теории
Ядро (kernel) главная программа системы, она запускается первой. Ядро управляет железом: процессором, памятью, дисками, сетью. Остальные программы сами к железу не обращаются. Они просят ядро: «прочитай файл», «отправь пакет», «дай память».
Аналогия: ядро — это двигатель машины. Сам по себе он никуда не едет, но без него ничего бы не работало. Linux, строго говоря — это и есть только  ядро
Дистрибутив. Одно ядро бесполезно: нужны команды (ls, cp), менеджер пакетов, службы, настройки. Дистрибутив — это ядро плюс весь этот набор, собранные и проверенные вместе. Аналогия: ядро — двигатель, дистрибутив — готовая модель машины. Двигатель может быть одинаковым, а комплектация разная.
Shell — программа, которая принимает команды и переводит их в запросы к системе и показывает результат. У Ubuntu shell — bash. Когда набирается ls ~, именно bash подменяет ~ на /home/alex и потом запускает программу ls. Аналогия: shell — это администратор на ресепшене. Ты говоришь ему, а он передаёт запрос дальше. 
Терминал — окно, в котором ты набираешь текст (например PowerShell с SSH)
Shell — программа внутри этого окна, которая понимает команды
Структура каталогов
В Linux нет дисков C: и D:. Есть одно дерево, и оно начинается с / (корня). Остальные диски тоже подключаются внутрь этого древа.
/etc Настройки системы и программ: /etc/passwd (пользователи), /etc/ssh/sshd_config («Этцетера» — всё про настройки)
/var Данные, которые меняются: логи в /var/log, базы, очереди (variable — переменное)
/home Домашние папаки пользователей: /home/alex (Дом)
/usr Установленные программы: /usr/bin/ls (Программы, только читаются)
/tmp Временные файлы, чистятся при перезагрузке (temporary)
/root домашняя папка root, а не корень / (Частая путаница)
