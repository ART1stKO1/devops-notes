## Пакеты — apt и dpkg
- Для чего я выполнил apt update перед установкой Nginx? Здесь две команды: сначала sudo apt update, затем sudo apt install nginx. update обновляет локальный список пакетов и доступных версий из репозиториев. install скачивает и устанавливает пакет и нужные зависимости.
- Чем отличаются задачи apt и dpkg? apt более самостоятельный, apt скачивает из репозитория, dpkg устанавливает с диска. Если нужных зависимостей нет, dpkg сам их из репозитория не скачает.
- Пример команды с моей ВМ: … sudo apt update nginx
 
## Диски и LVM
- Что я проверял через lsblk, а что — через df -h? lsldk Она показывает блочные устройства, например диски, разделы и тома LVM. df -h показывает занятое и доступное место на смонтированных файловых системах.,  df -h сколько места на файловых системах
- Что такое PV, VG и LV? Объяснить на одном примере своими словами. как разбивается диск, PV это разделы отданные под VM, VG это общий котёл, LV это тома нарезанные из котла. PV — диск или раздел, подготовленный для LVM. «Общий котёл» — хорошее описание VG: он объединяет место из одного или нескольких PV. LV — логический том, которому выделили место из этого «котла».
